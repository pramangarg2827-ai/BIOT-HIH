From one exhale to a result

The mask samples your breath, measures gas and humidity, and compares the pattern with a trained model.

Breath sampling

A pressure sensor detects the exhale and starts a controlled capture.

Sensor array

ENS160 air-quality (TVOC, eCO₂) plus BME280 humidity and temperature, corrected against a clean-air baseline.

On-device features

The ESP32 turns each exhale into 16 features before sending it over Bluetooth.

AI scoring

The model returns a 0–1 pattern score and a green, yellow or red band.

FAQ

Short answers about what this prototype can and can’t do.

Does BIOT diagnose cancer?

No. It scores a breath pattern against a model’s reference range. It is a research prototype, and any concern needs a doctor and clinical tests.

How accurate is it?

That depends on the data the model was trained on. If the page says the model is synthetic, the score only demonstrates the pipeline and has no clinical meaning.

What can change my result?

Food, drink, smoking, mouthwash, perfume and humidity all affect breath sensors. Record these conditions with each test.

How do I run a test?

Wait until the ring says Ready, press Start test, then exhale steadily for about 8 seconds. The mask purges before the next test.

Does it work on iPhone?

Not yet. Bluetooth in the browser needs Chrome or Edge on Windows, Mac, Linux or Android. Demo mode works everywhere.
